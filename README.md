# TRANSALMA APP

Frontend estático para GitHub Pages + Supabase.

Esta primera versión incluye:
- Inicio de sesión con Supabase Auth.
- Panel interno.
- Reporte de Mercancía.
- Reporte de Excepción.
- Historial básico.

## Configuración
1. Edita `config.js`.
2. Coloca la URL de Supabase y la clave pública anon/publishable.
3. Nunca publiques la `service_role` key.
4. Sube los archivos al repositorio de GitHub.
5. Activa GitHub Pages.
